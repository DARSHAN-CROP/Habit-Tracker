# Habit Tracker

Daily habit tracker with streaks and a 7-day view (Gujarati and English).

**Website (works on phone and PC, no install):** https://1darshankumarsavsani-blip.github.io/Habit-Tracker/

## Downloads (latest release)

- `Habit_Tracker.apk`: Android app (works offline, the whole app is inside).
- `Habit_Tracker_Windows.exe`: Windows launcher (opens the website in its own window; Edge or Chrome needed).

By Darshankumar Savsani (DARSHAN CORPORATION). Data stays on your device.

Honest note: tested in a headless browser only. The Android and Windows files have not been run on a real phone or PC yet.

Source code: `docs/` (website) and `app/` (Android wrapper around the same page).
